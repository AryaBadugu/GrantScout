# Grant Documents – Manual Download List

This directory stores official public grant documents for GrantScout.
**Do NOT commit PDF files to version control** – add `*.pdf` to `.gitignore`.

## How to Use
1. Download PDFs from the official URLs below.
2. Place them in `/data/grants/`.
3. Go to the **Upload & Ingest** tab in the Streamlit app and upload them, OR use the Load Synthetic Test Data button for quick testing.

## Notes
- **Only public-access documents.** No login-protected portals are accessed.
- Always verify grant details on the official portal before applying.
- Grant details change frequently. Re-ingest updated PDFs when they become available.
- For testing without real PDFs, use the **synthetic samples** in `/data/synthetic/`.
